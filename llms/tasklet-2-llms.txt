# Tasklet

> Tasklet is a cloud AI agent operating system for knowledge work. Teams describe tasks in plain English and Tasklet builds autonomous agents that connect to thousands of apps, any HTTP API, or MCP servers, then take real actions — pulling reports, updating CRMs, triaging email, processing data — running 24/7 on schedules or event triggers. Founded 2025 by Andrew Lee and Jonny Dimond (ex-Firebase / Shortwave); YC S26.

Note: Tasklet is a consumer of APIs and MCP servers, not a public developer-API provider. It exposes no OpenAPI, SDKs, or REST API reference of its own. The links below are its product and company surfaces.
