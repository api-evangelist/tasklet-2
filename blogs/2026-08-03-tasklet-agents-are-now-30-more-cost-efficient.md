Three recent upgrades — deferred tool calling, smarter delegation, and code-based tool calling — have made Tasklet agents about 30% more cost-efficient. Your agents now load tools only when they need them, hand routine work to cheaper models, and write code instead of reasoning through the same repetitive steps.
